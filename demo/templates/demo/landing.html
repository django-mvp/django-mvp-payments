django-mvp-payments

Pricing, checkout and subscription components. This page is where they get looked at while they are being built.

Nothing to see yet

The package is scaffolded and the test harness is green, but no components have been written. The first ones will appear under the drf-stripe namespace as <c-drf-stripe.plan-grid /> and friends, each rendered here as it lands.

How the JavaScript arrives

Stripe forbids self-hosting stripe.js, so a checkout component needs it loaded from Stripe's CDN. This demo page will load it that way. The package itself emits no script tag for it: loading the libraries a component needs is the host project's decision, made however that project already manages its frontend.
